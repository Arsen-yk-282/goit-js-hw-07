# goit-js-hw-11

GoIT JavaScript Homework 11 — Pixabay image search.

## Start

```bash
npm install
cp .env.example .env
```

Put your Pixabay key into `.env`:

```text
VITE_PIXABAY_API_KEY=YOUR_REAL_KEY
```

Then run:

```bash
npm run dev
```

For GitHub Pages add an Actions secret named `VITE_PIXABAY_API_KEY`.
